# الإعدادات والتشغيل

كل الإعدادات في ملف `.env`. انسخه من القالب:

```bash
cp .env.example .env
```

## المتغيرات

| المتغير | الافتراضي | الأثر |
|---|---|---|
| `NUMVERIFY_ACCESS_KEY` | فارغ | مفتاح المزوّد. **فارغاً يعمل المشروع بالتحقق المحلي وحده** |
| `NUMVERIFY_HTTPS` | `false` | `true` للخطط المدفوعة فقط — المجانية ترفضه بخطأ `https_access_restricted` |
| `ENRICH_WITH_API` | `true` | `false` يوقف كل الاستدعاءات الخارجية نهائياً |
| `DEFAULT_COUNTRY_CODE` | `SA` | يُطبَّق على الأرقام التي تبدأ بصفر. فارغاً يُرفض الرقم المحلي بلا رمز صريح |
| `AUTO_RETRY` | `true` | إعادة محاولة واحدة برمز الدولة الافتراضي. تكلفتها طلب إضافي |
| `CACHE_ENABLED` | `true` | تعطيله يعني طلباً جديداً لكل استعلام مكرر |
| `CACHE_TTL` | `86400` | عمر النتيجة المخزّنة بالثواني |

## سيناريوهات جاهزة

**عرض تجريبي عام على الإنترنت** — بلا مفتاح ولا استهلاك، آمن للنشر:

```env
NUMVERIFY_ACCESS_KEY=
ENRICH_WITH_API=false
DEFAULT_COUNTRY_CODE=SA
```

**تطوير محلي بحصة ضيقة** — يوفّر أقصى ما يمكن:

```env
NUMVERIFY_ACCESS_KEY=مفتاحك
ENRICH_WITH_API=true
AUTO_RETRY=false
CACHE_ENABLED=true
CACHE_TTL=604800
```

**إنتاج بخطة مدفوعة:**

```env
NUMVERIFY_ACCESS_KEY=مفتاحك
NUMVERIFY_HTTPS=true
AUTO_RETRY=true
CACHE_TTL=86400
```

## التشغيل

```bash
php -S localhost:8000 -t public
```

Composer اختياري: المشروع يحوي محمّلاً مدمجاً بنمط PSR-4. لكن الاختبارات تحتاجه:

```bash
composer install
composer test
```

## رفع دقة التحقق المحلي

```bash
composer require giggsey/libphonenumber-for-php
```

يتحوّل المحرك تلقائياً بلا تعديل سطر واحد. تتأكد من أسفل الصفحة: يتغيّر السطر من
`builtin` إلى `libphonenumber`.

## الأمان

المفتاح يُقرأ في الخادم فقط ولا يصل المتصفح إطلاقاً. و`.env` مستبعد في
`.gitignore`، فلا يُرفع إلى Git.

في مخرجات `bin/diagnose.php` يظهر الرابط بالمفتاح مُقنَّعاً `***`، فيمكن لصق
المخرجات في تقرير خطأ بأمان.

إن دخل المفتاح في تاريخ Git بالخطأ، لا يكفي حذف الملف — يجب **إبطال المفتاح من
لوحة numverify وإنشاء غيره**، لأن المحذوف يبقى في السجل.

## استكشاف الأخطاء

| العَرَض | السبب الأرجح |
|---|---|
| «مفتاح الوصول غير صحيح» رغم صحته | الخادم لم يُعد تشغيله بعد تعديل `.env` |
| «مفتاح الوصول غير صحيح» دائماً | المفتاح من `apilayer.com` لا من `numverify.com` — منصتان مختلفتان |
| رقم صالح يُرفض محلياً | دولته خارج جدول المحرك المدمج — ثبّت `libphonenumber` |
| نتيجة قديمة لا تتغيّر | الكاش — شغّل `php bin/cache-clear.php` |
| «رُفض محلياً» لرقم محلي | لم يُحدَّد `DEFAULT_COUNTRY_CODE` ولا رمز صريح |

للتشخيص الكامل:

```bash
php bin/diagnose.php <number>
```

يعرض المحرك المستخدم، ونتيجة التحقق المحلي، والرابط المُرسَل، والرد الخام — بلا
كاش وبلا إعادة محاولة.
